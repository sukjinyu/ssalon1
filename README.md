# 로열 살롱

까끌래뽀끌래2의 미용실 경영과 방향키 시술을 참고해 새로 만든 싱글플레이 웹 게임입니다. LG디스플레이 사내 로열 라운지를 가상의 배경으로 사용하고 공주·왕자 캐릭터가 등장합니다. 원작의 픽셀 단위 복제나 SWF 개조 버전은 아닙니다.

## 실행

Node.js **24 이상**이 필요합니다. 처음 받은 다른 컴퓨터에서는 프로젝트 폴더에서 다음을 실행하세요.

```sh
npm install
npm run build
npm start
```

브라우저에서 http://localhost:3000 을 여세요. 개발할 때는 `npm run dev`로 실행합니다. pnpm을 사용할 경우 제공한 `pnpm-lock.yaml`을 사용해 `pnpm install`, `pnpm build`, `pnpm start`를 실행할 수 있습니다.

현재 컴퓨터에는 의존성과 빌드 결과가 준비되어 있습니다. `시작.ps1`은 설치된 Node를 찾아 서버를 별도 창 없이 시작하고 브라우저를 엽니다. 서버 로그는 `data/server.log` 및 `data/server-error.log`에 남습니다.

## 조작

- 오른쪽 대기 손님 클릭 → 자동 이동 및 빈 의자 안내.
- 또는 방향키/WASD 이동 후 손님 근처에서 Space로 안내·선택.
- 숫자 1~8, Ctrl 반복 입력, 또는 오른쪽 도구 버튼으로 시술 도구 선택.
- Ctrl은 새 손님이나 새 시술 단계마다 다시 1번부터 셉니다. Ctrl 1번=커트, 2번=드라이, 3번=염색, 4번=파마, 5번=스트레이트, 6번=헤어변형, 7번=메이크업, 8번=왕실 업스타일입니다.
- 손님 앞 네모칸 안에서 올바른 도구를 고른 뒤 **Space를 5번** 누르거나 시술 버튼을 5번 클릭.
- 주문 시술 → 샴푸존을 각각 완료하면 자동 결제.
- 주문 시술이 끝나면 손님의 픽셀 캐릭터가 파마, 염색, 업스타일 등 결과 스타일로 바뀝니다.
- 잘못된 도구는 대기 시간을 4초 줄이고 콤보를 끊습니다.
- ESC 또는 일시정지 버튼. 다른 메뉴·창으로 이동하면 자동 일시정지.
- 손님 대기 시간이 다 되면 퇴장합니다. 시술 중에는 대기 시간이 천천히 줄어듭니다.
- 제한 시간 안에 목표 인원을 달성하면 다음 단계가 열립니다. 실패하면 재도전할 수 있습니다.

## 콘텐츠

10단계와 이후 무한 라운드, 커트·드라이·염색·파마·스트레이트·헤어변형·메이크업·왕실 업스타일, 자동 샴푸존, 6개 의자, 손님 기다림·팁·콤보·별점·매출.

무료 직원 3명: 민트 공주는 의자 시술과 드라이를 담당하고, 라일락 왕자는 샴푸존을 전담하며, 로제 공주는 대기 손님에게 커피를 줘서 기다림을 늘립니다. 현재 플레이어가 선택한 손님은 자동 배정에서 제외됩니다. 직원 작업은 매 단계 5초, 도구 업그레이드 적용 시 3초입니다. 직원은 언제든 배치/해제할 수 있습니다. 현금 결제, 고용비, 인건비는 없습니다.

무료 업그레이드 3종: 시술 입력 3회, 기다림 +25초, 팁 2배. 처음에는 해제되어 있어 직접 플레이할 수 있습니다. 관리 메뉴에서 원하는 만큼 켜세요. 기다림·입력 횟수 변경은 새 손님에게 적용됩니다.

## 기술 및 저장

- 프런트엔드: React + TypeScript + Vite
- 서버: Express.js + TypeScript, Node 24 네이티브 TypeScript 실행
- DB: Node 내장 `node:sqlite`의 실제 파일 기반 SQLite, `data/salon.sqlite`
- `GET /api/health`, `GET /api/save?player=별명`, `PUT /api/save`, `DELETE /api/save/:player`, `GET /api/players`, `GET /api/rankings`
- 별명별 저장 슬롯, 현재 별명 리셋, 순위 창, 상점 꾸미기, 진행 중 10초 자동 저장, 수동 저장 버튼, 단계 완료·직원 설정 저장
- 저장된 진행 중 게임은 일시정지 상태로 복원
- 데이터베이스는 같은 컴퓨터 안에서 별명별 로컬 저장 슬롯과 로컬 순위를 관리합니다. 온라인 계정/온라인 순위는 포함하지 않습니다.
- 서버는 로컬 컴퓨터(127.0.0.1)에서만 접속합니다. 서버가 종료되면 게임 링크도 열리지 않습니다.

원작과의 차이: 원작 자료로 확인한 핵심 시술 순서를 재구현했으며, 샴푸는 별도 샴푸존에서 처리합니다. 원작의 정확한 수치·연수·호감도·인건비 체계는 그대로 복제하지 않았습니다. 무료 직원, 상점 꾸미기, 10단계 이후 무한 라운드가 있는 새 밸런스입니다.

## 검증

`src/game.ts`: 단계별 목표/시간/시술 종류, 손님 생성, 샴푸존 이동, 거리 판정, 시술 진행, 직원 자동 처리.

`src/main.tsx`: React 화면, 키보드 입력, 저장 호출, 탭과 버튼 동작.

`src/style.css`: 픽셀 캐릭터, 살롱 배경, 반응형 레이아웃.

`npm test` : 올바른/잘못된 도구, 손님 앞 네모칸 거리 제한, 모든 단계 수동 시술 시뮬레이션, 모든 단계 무료 직원 시뮬레이션, 후반 8종 시술 해금, 무한 라운드, 상점 꾸미기, 일시정지·시간 초과·퇴장, SQLite 왕복 저장, 별명별 저장·리셋·랭킹, 잘못된 데이터 거부. 시뮬레이션은 게임 엔진 테스트이며 사람이 모든 단계를 직접 플레이한 결과를 뜻하지 않습니다.

`npm run build` : TypeScript 검사와 배포용 정적 파일 빌드.
